# Spam Email Classifier

## Overview
This project uses Machine Learning to classify SMS/Email messages as Spam or Ham.

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- TF-IDF Vectorization
- Multinomial Naive Bayes

## Dataset
SMS Spam Collection Dataset

## Results
- Accuracy: 96.68%
- Successfully classifies spam and non-spam messages
